Catalogación asistida de monografía moderna impresa

Tipo está diseñado en esta beta para la precatalogación y catalogación asistida de monografía moderna impresa. Suba el libro completo y la herramienta localizará las zonas descriptivas para proponer una descripción estructurada revisable. El procesamiento se realiza en local mediante Ollama.

Alcance de esta beta: monografía moderna impresa. Tipo no consulta catálogos externos, no crea autoridades ni puntos de acceso autorizados, no asigna materias normalizadas y no modifica sistemas bibliotecarios.

1. El libro

Beta especializadaEsta versión está pensada para monografía moderna impresa. No está optimizada para manuscritos, fondo antiguo, publicaciones seriadas ni recursos electrónicos.

Suba el libro completo. No hace falta separar portada, verso o colofón: Tipo localiza internamente las zonas relevantes y descarta el cuerpo. También puede subir imágenes sueltas si lo prefiere.

2. Resultado

Cómo usar Tipo

  1. Suba el libro completo en PDF, imágenes o DOCX. Tipo localiza por sí mismo las páginas donde están los datos.
  2. Elija el idioma de salida y el modo: Esencial para los campos catalográficos básicos; Completo para todos los campos del esquema.
  3. Opcionalmente, complete los Valores institucionales predefinidos para que se apliquen como fallback cuando un campo venga vacío.
  4. Pulse Procesar. Tipo extrae los datos atómicos y ensambla los bloques ISBD por área.
  5. Revise la pestaña Campos. Semáforo: verde = alta confianza, ámbar = revisar, rojo = baja.
  6. Use Vista ISBD para validar la descripción ya con su puntuación. Al final aparece la ficha completa lista para copiar.
  7. Use MARC21 para ver el registro etiquetado y pegarlo directamente en su OPAC.
  8. Exporte en el formato que necesite o copie cada campo/línea con su botón ⧉.

Lo que Tipo NO hace

  • No consulta catálogos externos ni autoridades.
  • No crea puntos de acceso autorizados.
  • No asigna materias normalizadas.
  • No modifica sistemas bibliotecarios.

Normativa aplicada

Tipo emplea descripción ISBD por áreas y proyecta los campos atómicos a MARC21. Esta es la normativa de referencia que aplica el modelo y los exportadores deterministas.

Áreas ISBD cubiertas

  • Área 0 — Forma del contenido y tipo de medio. En monografía impresa: "Texto (visual) : sin mediación".
  • Área 1 — Título y mención de responsabilidad. Fuente: portada.
  • Área 2 — Edición. Solo si hay mención explícita; reimpresión no es edición.
  • Área 4 — Publicación, distribución. Fuente: portada / verso / colofón. Si la fecha solo consta en D.L. o ©, se antepone "D.L." o "cop.".
  • Área 5 — Descripción física. Requiere observación directa del ejemplar.
  • Área 6 — Serie. Entre paréntesis, con punto y coma antes del número.
  • Área 7 — Notas. Breves y útiles. La ilustración de cubierta NO se anota.
  • Área 8 — ISBN y depósito legal, una línea por identificador.

Jerarquía de fuentes

  1. Portada: fuente principal de título y responsabilidad.
  2. Verso de portada: fuente principal de edición, publicación, ©, ISBN, depósito legal.
  3. Cubierta, lomo, colofón: fuentes complementarias.
  4. Resto del material: solo como apoyo.

Proyección a MARC21

  • 020 $a ISBN · 017 $a D.L.
  • 041 lengua y, si procede, $h idioma original
  • 240 título uniforme / título original (si aplica)
  • 245 0 _ $a $b $c título, subtítulo, responsabilidad
  • 250 $a edición
  • 264 _ 1 $a $b $c lugar, editor, fecha
  • 300 $a $b $c extensión, ilustraciones, dimensiones
  • 336 / 337 / 338 tipo de contenido / medio / soporte
  • 490 0 $a serie transcrita
  • 500 / 504 / 520 / 546 notas (general, bibliografía, resumen, lengua)

Alcance

Tipo no crea puntos de acceso autorizados (campos 1xx, 7xx, 6xx, 110, 111). El profesional asigna el encabezamiento principal y los secundarios según el caso (autor único, obra colectiva, anónima, actas de congreso, etc.). Tipo proporciona los datos atómicos suficientes para que esa decisión sea inmediata.
