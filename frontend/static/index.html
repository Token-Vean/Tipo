Asistente local de precatalogación

Extracción bibliográfica para monografías impresas

Suba imágenes del libro y Tipo propondrá datos descriptivos estructurados para revisión profesional. El procesamiento se realiza en local mediante Ollama.

Tipo no consulta catálogos externos, no crea puntos de acceso autorizados, no asigna materias normalizadas y no modifica sistemas bibliotecarios.

1. Fuentes del libro

Añada portada, verso de portada, cubierta, contracubierta, lomo, colofón, índice u otras imágenes.

La propuesta se generará en el idioma seleccionado para la interfaz.
